How to ask

One prompt, three parts — hardware, limits, idea.
1 Define your hardware
"I have a micro:bit v2 on a RobotBit, an HC-SR04 on P1 (Trig) / P2 (Echo), and two servos — one on S1, one on S2."
2 Set the limits (optional)
"Servo S1 can only go from 0° to 70°."
3 Describe the idea
"Make S1 sweep the sensor like a radar and show the distance on a web page."
💡 The more you specify, the better — then Claude Code builds, flashes & runs it.
